# Uncodixfy

Design interfaces with clear structure, sufficient information, consistent components, and visual character suited to their purpose. Avoid interchangeable AI templates without replacing them with a single rigid aesthetic.

## Design guidance

- Establish a consistent grid, hierarchy, spacing scale, and component system.
- Keep operational interfaces predictable, with useful table density and clear actions.
- Let public pages express their subject through typography, imagery, color, and geometry.
- Treat rectangles, curves, rounded forms, and irregular silhouettes as equally available design materials.
- Remove decorative labels, redundant explanations, and unsolicited disclaimers while preserving useful content and narrative depth.

## Install

```sh
npx skills add nyan-mikan/Uncodixfy
```

For Codex, invoke the installed skill with `$uncodixfy`. Automatic skill selection is enabled through `agents/openai.yaml`.

[SKILL.md](SKILL.md) is the agent entry point. [Uncodixfy.md](Uncodixfy.md) contains the same instructions without skill metadata and can be included directly in a prompt.
